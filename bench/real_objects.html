Mapping on real object scans

Five everyday objects, using public scans from the YCB Object and Model Set. Inspect the original texture, applied checker pattern, and measured problem areas.

These are real scanned shapes viewed through synthetic cameras with known poses. This does not validate live phone tracking, scanning, lighting, or hand occlusion. No object passes the full appearance release gate yet.
